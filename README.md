# CreatorCircle

A mobile-first creator community MVP for Telugu + English YouTube creators.

## Included
- Creator registration and login (hashed passwords, server-side sessions)
- Creator profiles with channel, niche, language and subscriber range
- Algorithmic creator suggestions based on niche, language and goals
- Collaboration requests and creator feedback community
- Content idea library and script templates (starter content)
- ₹19/month membership request flow with UPI payment reference
- Admin dashboard to approve/reject membership requests and manage ideas
- No subscription exchange, Sub4Sub, view-for-view or engagement trading

## Run locally
1. Install Node.js 20+
2. Copy `.env.example` to `.env` and change the secrets/password.
3. Run `npm install`
4. Run `npm start`
5. Open http://localhost:3000

The first configured admin is created from `ADMIN_EMAIL` and `ADMIN_PASSWORD` on startup.

## Membership payment flow
This MVP uses manual UPI verification. Set `UPI_ID` and `UPI_PAYEE` in environment variables. Members submit their UPI transaction/reference number; admin checks their payment in their UPI/bank app and approves the request. Approval grants 30 days from approval. It does not collect or store UPI PINs, card data or bank passwords.

This is NOT automatic payment verification. For automatic recurring billing, integrate a compliant payment provider and recurring mandate flow before launch.

## Deploy on Render
- Push this folder to a GitHub repository.
- Create a Render Web Service from that repository.
- Set `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `UPI_ID`, `UPI_PAYEE`.
- Keep `SESSION_SECRET` generated by Render.
- Important: Render's free filesystem is ephemeral. SQLite data can be lost on redeploy/restart. Before accepting real users/payments, migrate the database to managed PostgreSQL or attach persistent storage. Do not treat the free instance as production-ready.

## Before public launch
